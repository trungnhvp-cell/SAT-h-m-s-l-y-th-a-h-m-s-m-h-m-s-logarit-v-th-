I Hàm số lũy thừa (Power Functions)

Tiếng ViệtEnglish
Hàm số lũy thừa có dạng \(y = x^\alpha\) với \(\alpha \in \mathbb{R}\).A power function has the form \(y = x^\alpha\) where \(\alpha \in \mathbb{R}\).
Nếu \(\alpha\) nguyên dương: TXĐ là \(\mathbb{R}\); nếu \(\alpha\) nguyên âm hoặc bằng 0: TXĐ là \(\mathbb{R}\setminus\{0\}\).If \(\alpha\) is a positive integer: domain \(\mathbb{R}\); if \(\alpha\) is negative or zero: domain \(\mathbb{R}\setminus\{0\}\).
Nếu \(\alpha\) không nguyên: TXĐ là \((0, +\infty)\).If \(\alpha\) is not an integer: domain \((0, +\infty)\).
Đạo hàm: \((x^\alpha)' = \alpha x^{\alpha-1}\).Derivative: \((x^\alpha)' = \alpha x^{\alpha-1}\).
Lưu ý: \(\sqrt[n]{x} = x^{1/n}\), \(\sqrt[n]{x^m} = x^{m/n}\), \(\dfrac{1}{x^n} = x^{-n}\).

II Hàm số mũ (Exponential Functions)

Định nghĩa: \(y = a^x\) với \(a > 0,\ a \neq 1\).
TXĐ: \(\mathbb{R}\), TGT: \((0, +\infty)\).
Tính chất đồ thị: Luôn đi qua điểm \((0; 1)\), nhận trục \(Ox\) làm tiệm cận ngang.
Nếu \(a > 1\): hàm số đồng biến trên \(\mathbb{R}\). Nếu \(0 < a < 1\): hàm số nghịch biến trên \(\mathbb{R}\).
Đạo hàm: \((a^x)' = a^x \ln a\); \((e^x)' = e^x\).
Đẳng thức cơ bản: \(a^m \cdot a^n = a^{m+n}\), \(\dfrac{a^m}{a^n}=a^{m-n}\), \((a^m)^n = a^{mn}\), \((ab)^n = a^n b^n\).

III Hàm số logarit (Logarithmic Functions)

Định nghĩa: \(\log_a b = c \iff a^c = b\) với \(a > 0,\ a \neq 1,\ b > 0\).
Hàm số: \(y = \log_a x\) với \(a > 0, a \neq 1\). TXĐ: \((0, +\infty)\), TGT: \(\mathbb{R}\).
Đồ thị: Luôn đi qua \((1; 0)\), nhận trục \(Oy\) làm tiệm cận đứng.
Nếu \(a > 1\): hàm số đồng biến; nếu \(0 < a < 1\): hàm số nghịch biến trên \((0, +\infty)\).
Logarit tự nhiên: \(\ln x = \log_e x\). Logarit thập phân: \(\log x = \log_{10} x\).

IV Tính chất của logarit (Properties of Logarithms)

Công thứcEnglish
\(\log_a 1 = 0\), \(\log_a a = 1\)\(\log_a 1 = 0\), \(\log_a a = 1\)
\(\log_a(b \cdot c) = \log_a b + \log_a c\)Product rule
\(\log_a \dfrac{b}{c} = \log_a b - \log_a c\)Quotient rule
\(\log_a b^n = n\log_a b\)Power rule
\(\log_a b = \dfrac{\log_c b}{\log_c a}\) (đổi cơ số)Change-of-base formula
\(a^{\log_a b} = b\), \(\log_a a^b = b\)Inverse identities
\(\log_a b = \dfrac{1}{\log_b a}\)Reciprocal property

V Phương trình & Bất phương trình (Equations & Inequalities)

Phương trình mũ cơ bản: \(a^x = b \iff x = \log_a b\) (với \(a>0, a\neq 1, b>0\)).
Phương trình mũ cùng cơ số: \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\).
Phương trình logarit cơ bản: \(\log_a x = b \iff x = a^b\).
Phương trình logarit cùng cơ số: \(\log_a f(x) = \log_a g(x) \iff f(x) = g(x) > 0\).
Bất phương trình: Nếu \(a > 1\): \(a^{f} > a^{g} \iff f > g\). Nếu \(0 < a < 1\): \(a^{f} > a^{g} \iff f < g\).

VI Ứng dụng thực tế (Real-World Applications)

Lãi kép: \(A = P\left(1 + \dfrac{r}{n}\right)^{nt}\); liên tục: \(A = Pe^{rt}\).
Tăng trưởng/suy giảm mũ: \(N(t) = N_0 e^{kt}\) (\(k>0\): tăng, \(k<0\): giảm).
Chu kỳ bán rã: \(N(t) = N_0\left(\dfrac{1}{2}\right)^{t/T}\) (\(T\) = half-life).
Thang đo pH: \(\text{pH} = -\log[\text{H}^+]\). Độ Richter: \(M = \log \dfrac{I}{I_0}\). Decibel: \(L = 10\log \dfrac{I}{I_0}\).
